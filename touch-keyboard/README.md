# 盲打触控键盘（iPad 网页原型）

验证一个想法：屏幕是平的，但边缘摸得到。用边缘做物理锚点，按每个人自己的落点建键盘映射，打字时再慢慢跟随手的漂移。

打开：`/touch-keyboard/`（iPad Safari，建议横屏、添加到主屏幕后全屏使用）。第一次打开先显示介绍页，`?intro` 可以再看一遍。

界面有中文、English、Deutsch，默认跟浏览器语言，菜单、顶栏和介绍页都能切换。输入目前只做英文。

## 流程
1. 校准：摸左下角和右下角 → 八指放在 home row 按住 → 拇指敲 6 下空格 → 盲打 4 句覆盖全部字母的句子。
2. 自由练习 / 测试：拇指 = 空格，⇧ 点一下 = 下个字母大写、按住 = 一直大写，左滑 = 删除，右滑 = 换行或提交，八指同时按住 = 重新对位，按住不动超过 300ms 的手指算“休息”不出字。
3. 找位置练习：摸角落后放手，量每次落点和校准位置差几毫米。
4. 数据：按条件（映射+解码 / 映射无解码 / 系统键盘）对比 WPM、未纠正错误率、KSPC，可复制 JSON。

## 触碰录制
网址加 `?rec`（例如 `/touch-keyboard/?rec`）后顶栏出现红色录制按钮，之后一直保留，`?norec` 关闭。录下每个触点的开始/移动/抬起（时间、编号、坐标）和屏幕输出，在录制面板里下载 JSON。介绍页的回放就是用这种格式画出来的（`DEMO_REC`，目前是模拟数据）。

## 算法
- 每个键一个二维高斯（均值 + 协方差），初值由八指 home row 的几何关系推出，再用校准句子的落点收缩估计。
- 词级解码：同长度词典词按 Σ 落点对数似然 + 词频打分，词典外原样输出要付额外代价。
- 跟随：只用置信度 > 0.9、在词典里、且之后没被删改的词更新；整手偏移快跟（0.25），单键慢跟（0.05），单键离校准位置不超过半个键距。
